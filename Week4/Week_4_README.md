# Week 4: Azure Cloud Fundamentals and Data Pipeline Implementation using ADF

## Objective
To understand Azure cloud concepts and implement an end-to-end data pipeline using Azure Storage Account and Azure Data Factory.

## Technologies Used
- Microsoft Azure
- Azure Storage Account
- Azure Blob Storage
- Azure Data Factory (ADF)

## Implementation
- Created Azure Resource Group
- Created Storage Account and Blob Containers
- Uploaded CSV dataset to Blob Storage
- Created Azure Data Factory
- Configured Linked Service and Source/Destination Datasets
- Implemented Get Metadata activity for file validation
- Built pipeline using Copy Data activity
- Executed and monitored pipeline successfully
- Configured IAM roles for secure access

## Output
The pipeline successfully copied data from Blob Storage source to destination with metadata validation.
