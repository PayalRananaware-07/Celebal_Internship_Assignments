# Week 8: Ecommerce Analytics System

## Overview
Built an end-to-end eCommerce analytics system using SQL and Python.

## Features
- SQL queries for business insights
- Python CLI reporting tool
- Revenue, orders, customer metrics
- Top product analysis
- Edge case handling

Folder Structure

Ecommerce_Analytics/
│
├── data/
│ ├── raw/ # Raw generated datasets
│ └── cleaned/ # Cleaned and processed data
│
├── scripts/

│
├── sql/

│
├── reports/
